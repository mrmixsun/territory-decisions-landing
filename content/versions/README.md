# Версии текста лендинга

| Версия | Дата | Что изменилось |
|---|---|---|
| `v1-исходная` | 17.09.2026 | Первая интегрированная редакция, более терминологическая. Сохранены JSON и читаемый Markdown. |
| `v2-человечная` | 17.09.2026 | Переписаны заголовки, основные абзацы, подписи и навигация для читателя без подготовки. Фактические ограничения Концепции сохранены. |
| `strict/s1.0` | 17.09.2026 | Первая редакция строгой ветки: сдержанный тон, точные формулировки, сохранены примеры и пояснения без канцелярской перегрузки. |
| `strict/s1.1-desktop` | 17.09.2026 | Реакция на комментарии к s1.0: короткий знак, роль НОТИМ, иллюстрированная история вместо длинного объяснения, компактные карточки и картографическая цветовая гипотеза. Десктопная итерация; мобильная не согласовывалась. |

Активная локальная версия — `strict/s1.1-desktop` — лежит в `../landing.json`; сайт собирается только из неё. `../landing.md` автоматически создаётся для чтения и обсуждения. Файлы версий не подставляются на сайт, поэтому следующую редакцию можно готовить и сравнивать, не теряя предыдущую. Опубликованная версия в GitHub Pages остаётся `v2-человечная`.

Две дальнейшие линии работы: **строгая** (`strict/s…`) и **понятная для широкой аудитории** (`plain/p…`). Сохранённая `v2-человечная` — исходная точка второй линии. `v1-исходная` остаётся историей первого прототипа, а не целевой редакцией строгой линии.

Полный текст Концепции (`../full-text.md`) в этой итерации не переписывался.
