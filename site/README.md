# Веб-прототип Концепции

Статический сайт без внешних зависимостей. Исходные тексты берутся из `../content/`, графика и дизайн-токены — из `../design/`; в этой папке находятся только код сайта и результат сборки.

## Локальный просмотр

Из папки `site/`:

```sh
npm run dev
```

Откройте адрес, который появится в терминале (по умолчанию `http://localhost:4173/`). После изменения исходных текстов, графики или стилей перезапустите команду.

## Готовая статическая версия

```sh
npm run build
npm run check
```

Готовые файлы находятся в `dist/`. Внутренние ссылки относительные: папка работает как в корне сайта, так и по пути репозитория GitHub Pages (например, `/concept-preview/`). При тестовом размещении надо публиковать только содержимое `dist/` в отдельном согласованном репозитории, не всю базу знаний. Эти команды ничего не отправляют в GitHub.

Для будущего GitHub Pages: создайте отдельный репозиторий для прототипа, скопируйте в его публикуемую папку **содержимое** `dist/` (не папку `dist` целиком, если Pages настроен на корень), затем откройте `index.html` и `concept.html` по адресу Pages. Проверьте переходы между страницами, изображения и якоря, особенно при адресе вида `https://<аккаунт>.github.io/<репозиторий>/`. Абсолютных путей от корня домена сайт не использует; отдельная переменная базового пути не требуется.

## Архитектура

- `../content/landing.json` — тексты главной страницы и подписи.
- `../content/full-text.md` — рабочая полная версия. Сборка преобразует её в `concept.html` и создаёт устойчивые якоря `m1`…`m12`.
- `../design/tokens.json` — единый источник цветов, типографики, сетки и вариантов акцента.
- `../design/assets/` — редактируемые SVG; копируются в `dist/assets/` без растрирования.
- `src/` — разметка/стили/небольшой скрипт меню.

Рабочий акцент пока сливовый. Перед внешней публикацией решение о цвете, публичном статусе и контакте остаётся за Михаилом.
